# wrtbox

Signed OpenWrt 25.12 APK feed for the official sing-box OpenWrt release packages.

The feed is generated by GitHub Actions and deployed as static assets to the `wrtbox` Cloudflare Worker:

```text
https://wrtbox.czuouo.workers.dev/openwrt-25.12/<apk-arch>/packages.adb
```

The router downloads the small signed index and public key from the wrtbox Worker. The index points the larger official sing-box APK download through GH-Proxy, so the router does not need direct GitHub access.

## Router setup

```sh
apk add curl ca-bundle
wget -O /etc/apk/keys/wrtbox.pem https://wrtbox.czuouo.workers.dev/public-key.pem
ARCH="$(cat /etc/apk/arch)"
echo "https://wrtbox.czuouo.workers.dev/openwrt-25.12/${ARCH}/packages.adb" \
  > /etc/apk/repositories.d/wrtbox.list
apk update
apk add sing-box
```

The feed currently targets `gh-proxy.org` for the APK asset because Cloudflare static assets have a 25 MiB per-file limit while the official sing-box APK is larger. The feed index and signing key remain hosted by the wrtbox Worker.

The first rollout targets `aarch64_generic`. More OpenWrt 25.12 architectures can be added to the workflow matrix later.

## Security

The repository contains only public workflow code and the feed public key. The APK signing private key and Cloudflare credentials must be stored as GitHub Actions secrets and must never be committed.
