## Feed 地址

The feed is generated by GitHub Actions and deployed as static assets to the `wrtbox` Cloudflare Pages project:

```text
https://wrtbox.pages.dev/openwrt-25.12/stable/<apk-arch>/packages.adb
```

The router downloads the signed index and public key from wrtbox Pages. GitHub Actions keeps the unchanged official sing-box prebuilt binary, re-signs its APK container with the feed key, and publishes it as a GitHub Release asset. The index points to that asset through GH-Proxy, so the router does not need direct GitHub access.

## 路由器安装

### Stable 通道

The feed installer detects the OpenWrt release and architecture, installs the
signing key, writes the APK repository, and refreshes the package index:

```sh
wget -O - https://wrtbox.pages.dev/feed.sh | ash -s stable
```

The installer removes existing wrtbox entries before adding the selected
channel. Other feeds, including momo, are left untouched.

Then install from SSH if desired:

```sh
apk add sing-box
```

Or open LuCI **System → Software**, click **Update lists**, search for
`sing-box`, and install or upgrade it there.

### Beta 通道

Beta follows the newest official prerelease returned by GitHub. That may be
labeled alpha, beta, or release candidate upstream.

```sh
wget -O - https://wrtbox.pages.dev/feed.sh | ash -s beta
```

### 手动配置

```sh
apk add ca-bundle
wget -O /etc/apk/keys/wrtbox.pem https://wrtbox.pages.dev/public-key.pem
ARCH="$(cat /etc/apk/arch)"
echo "https://wrtbox.pages.dev/openwrt-25.12/stable/${ARCH}/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add sing-box
```

## Feed 工作方式

The installer currently supports OpenWrt 25.12, including ImmortalWrt 25.12.
When a new OpenWrt series is published, the feed workflow and installer can
be extended to add that series without changing the existing 25.12 URL.

The feed currently targets `gh-proxy.org` for the APK asset because Cloudflare static assets have a 25 MiB per-file limit while the official sing-box APK is larger. The feed index and signing key remain hosted by wrtbox Pages; the signed package is published in this repository's GitHub Release assets.

Stable follows the latest official GitHub release. The two channels use
the official version tag (`sing-box-v...`); the feed path continues to
distinguish the stable and beta channels.

## 支持范围

The workflow currently publishes the OpenWrt 25.12 APK feed for the official
sing-box architecture set used by the matrix, including `aarch64_generic`,
`aarch64_cortex-a53`, `x86_64`, MIPS, ARM, RISC-V, and LoongArch variants.
OpenWrt 24.10 is not included because it uses opkg/IPK rather than APK. New
APK-based OpenWrt series can be added as another matrix branch after their SDK
and feed mapping are available.

## 安全说明

The repository contains only public workflow code and the feed public key. The APK signing private key and Cloudflare credentials must be stored as GitHub Actions secrets and must never be committed.
