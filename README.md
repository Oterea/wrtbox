# wrtbox

Signed OpenWrt 25.12 APK feed for the official sing-box OpenWrt release packages.

The feed is generated by GitHub Actions and deployed as static assets to the `wrtbox` Cloudflare Worker:

```text
https://wrtbox.czuouo.workers.dev/openwrt-25.12/<apk-arch>/packages.adb
```

The router downloads the signed index and public key from the wrtbox Worker. GitHub Actions keeps the unchanged official sing-box prebuilt binary, re-signs its APK container with the feed key, and publishes it as a GitHub Release asset. The index points to that asset through GH-Proxy, so the router does not need direct GitHub access.

## Router setup

### One-command setup

The feed installer detects the OpenWrt release and architecture, installs the
signing key, writes the APK repository, and refreshes the package index:

```sh
wget -O - https://wrtbox.czuouo.workers.dev/feed.sh | ash
```

Then install from SSH if desired:

```sh
apk add sing-box
```

Or open LuCI **System → Software**, click **Update lists**, search for
`sing-box`, and install or upgrade it there.

### Manual setup

```sh
apk add curl ca-bundle
wget -O /etc/apk/keys/wrtbox.pem https://wrtbox.czuouo.workers.dev/public-key.pem
ARCH="$(cat /etc/apk/arch)"
echo "https://wrtbox.czuouo.workers.dev/openwrt-25.12/${ARCH}/packages.adb" \
  >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add sing-box
```

The installer currently supports OpenWrt 25.12, including ImmortalWrt 25.12.
When a new OpenWrt series is published, the feed workflow and installer can
be extended to add that series without changing the existing 25.12 URL.

The feed currently targets `gh-proxy.org` for the APK asset because Cloudflare static assets have a 25 MiB per-file limit while the official sing-box APK is larger. The feed index and signing key remain hosted by the wrtbox Worker; the signed package is published in this repository's GitHub Release assets.

The workflow currently publishes the OpenWrt 25.12 APK feed for the official
sing-box architecture set used by the matrix, including `aarch64_generic`,
`aarch64_cortex-a53`, `x86_64`, MIPS, ARM, RISC-V, and LoongArch variants.
OpenWrt 24.10 is not included because it uses opkg/IPK rather than APK. New
APK-based OpenWrt series can be added as another matrix branch after their SDK
and feed mapping are available.

## Security

The repository contains only public workflow code and the feed public key. The APK signing private key and Cloudflare credentials must be stored as GitHub Actions secrets and must never be committed.
